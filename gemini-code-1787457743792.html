เกี่ยวกับฉัน

สวัสดีครับ! ผมชื่อ Tasid ปัจจุบันกำลังศึกษาอยู่ชั้นมัธยมศึกษาตอนปลาย มีความสนใจเป็นพิเศษด้านการพัฒนาเว็บและซอฟต์แวร์

ผมชอบเรียนรู้สิ่งใหม่ๆ เสมอ และมักใช้เวลาว่างในการฝึกเขียนโปรแกรม ทำโครงงานคอมพิวเตอร์ รวมถึงเข้าร่วมการแข่งขันด้านเทคโนโลยีต่างๆ

ผลงานของฉัน

รูปภาพโครงงาน 1

เว็บไซต์ชมรมโรงเรียน

โครงงานพัฒนาเว็บไซต์สำหรับประชาสัมพันธ์กิจกรรมของชมรม ใช้ HTML, CSS และ JavaScript

รูปภาพโครงงาน 2

แอปคำนวณเกรดเฉลี่ย

มินิโปรเจกต์ช่วยเพื่อนๆ คำนวณเกรดเฉลี่ยสะสมประจำเทอมอย่างง่าย
